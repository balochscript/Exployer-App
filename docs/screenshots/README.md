# Screenshots

Two sets, both 1080 × 1920:

- **`en/`** — seven feature sheets in English (one sheet per core area, with feature chips next to
  every screenshot).
- **`fa/`** — the seven screenshots that are live on the app's Cafe Bazaar listing, in Persian.

Both sets show the same seven areas — the file manager, folder playback, the video player, the music
player, tags, the browser and the download manager. The English set is numbered from the file manager
(01) to downloads (07); the Cafe Bazaar set keeps the store's own order (downloads first).

## How they are built

They come from the app's own design material, not from a stock mockup builder:

- **Palette** — the app's own indigo/cyan/amber theme and category accents.
- **Icons** — the same line icons the app draws in its lists, bars and tool tiles.
- **Type** — Inter for headings, Manrope for body text (both under the SIL Open Font License).
- **Content** — every headline, chip and screenshot pair states a feature that is really in the app;
  numbers visible inside the screenshots come from the screenshots themselves.

## Accuracy rules used for captions

- "Nine orders" — the app has exactly nine playback orders (name A→Z / Z→A, date newest / oldest,
  size largest / smallest, least played, most played, random).
- "Each file plays once" in multi-tag playback — enforced by the app's queue deduplication.
- No ad-blocking counter is claimed anywhere; the vault is described as AES-256 with a master password.
- The browser sheet does not claim always-on privacy headers: Do Not Track / Sec-GPC exist as an
  optional switch (off by default), and data saver is off by default too.
